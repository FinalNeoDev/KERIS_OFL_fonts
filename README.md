[![License: OFL](https://img.shields.io/badge/License-OFL-blue.svg)](https://scripts.sil.org/OFL)

> **OFL 라이선스 폰트를 웹 프로젝트에서 쉽고 편하게 불러와 사용하기 위한 저장소입니다.**

---

## 📌 주요 안내 사항

* **라이선스 주의**: KERIS 공모 폰트를 제외한 기타 폰트의 정확한 사용 범위는 **각 폰트 제작사의 규정**에 따라 다를 수 있습니다. 반드시 사용 전 확인해 주시기 바랍니다.
* **면책 조항**: 공공 목적의 무료 폰트로 제공되며, 폰트 사용 결과에 대한 법적 책임은 지지 않습니다.

## 🚀 웹폰트로 불러와 사용하기 (예시)

```css
/* CSS 파일 최상단에 폰트를 import 합니다. (실제 경로로 수정 필요) */
@import url('https://웹폰트_경로를_여기에_입력하세요.css');

body {
    font-family: '적용할폰트이름', sans-serif;
}
```
